# ADR-008：新 mod：Iteration（迭代）→ Evolve（进化）

状态：v0.1.0 已构建安装（2026-08-10），2026-08-11 修订（移除形状守卫/API 检测、封面替换），待实机验证

日期：2026-08-10

## 背景

用户希望把塔2 故障机器人卡牌“迭代”（Iteration）替换为塔1 铁甲战士卡牌“进化”（Evolve）的效果；先适配 public beta 110，同一产物面向 default 107（用户自测），并尽量不随版本迭代特意适配。

## 决策

1. 新建第 5 个单卡替换 mod（系列仓库内 `9.SRC/EvolveReplacementMod/`），沿用“最小 Harmony 补丁 + pck 素材”路线，不依赖 BaseLib/RitsuLib。
2. 核心机制仅两个补丁：`Iteration.CanonicalVars` 基础值 2→1；`IterationPower.AfterCardDrawn` 去掉“每回合第一次”限制（`num <= 1`）。OnPlay/OnUpgrade/费用/类型/稀有度/目标均无需改动。
3. 用户拍板：**整卡替换**（卡名“进化”、塔1 文案/卡图、Buff 名/图标）；**保留塔1 数值**（基础 1、升级 2）；命名 `EvolveReplacementMod` / “进化 (Evolve)”。
4. 版本兼容：107/110 源码已逐行比对一致，单一 DLL、`min_game_version=0.107.1`、无版本分支；形状守卫 + API 存在性检查保障未来版本自动降级。
5. 本地化：15 语言目录（zhs/zht/eng/jpn/kor/spa/esp/ptb/fra/deu/rus/ita/pol/tha/tur），键 `RE_EVOLVE.*` / `RE_EVOLVE_POWER.*`，文案取塔1 原文按系列方案 B 排版；已输出 `3.DOCS/003-T-进化15语言译文与转换规则.md` 待用户排版批准。
6. 素材：塔1 jar 提取 evolve.png 与 EvolvePower 图标；模组图标先占位。

## 依据

- 本机 v0.110.1 反编译：Iteration/IterationPower 行为与本地化键确认。
- `refs/decompiled-107`（本机反编译目录，不入库）：107 与 110 两个文件逐行一致，依赖 API 签名一致。
- 塔1 `desktop-1.0.jar`：Evolve/EvolvePower 文本、卡图、图标 atlas 确认。
- 系列既有先例：RecycleReplacementMod（同为 107/110 单 DLL）、PhantomKillerMod（Buff 文本/图标替换）、CorpseExplosionReplacementMod（自定义 Power 与形状守卫）。

## 影响

- 修改 IterationPower 会同时影响所有 IterationPower 实例；目前全库仅 Iteration 使用，影响面可控，记为已知边界。
- 去掉每回合限制后，连续抽到状态牌会连锁抽牌（塔1 同款语义），需实机验证无异常。
- 若未来版本改动 Iteration 形状或 hook 签名，补丁自动失效而非崩溃。
