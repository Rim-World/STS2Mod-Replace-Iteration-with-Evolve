### 开发人员反馈

- 2026-08-10 需求：把塔2 故障机器人卡「迭代」（Iteration）替换为塔1 铁甲战士卡「进化」（Evolve）。
- 同日拍板四项：①**整卡替换**（卡名「进化」、塔1 文案/卡图、Buff 名/图标）；②**保留塔1 数值**（基础 1、升级 2）；
  ③命名 `EvolveReplacementMod` / 显示名「进化 (Evolve)」；④**15 语言全量**，使用 `RE_` 专属键前缀。
- 2026-08-11 用户要求：移除「运行时按卡牌形状与 Buff 方法签名自动检测、不满足即自动关闭」的守卫机制；
  mod 封面改用用户提供的 `pics/Evolve_small.png`。
- 未记录：实机验收反馈。ADR 与计划自始至终标注「待 beta 110 实机验证」。

### 实装更改概括

- 新增 Godot + C# mod 工程，清单 `min_game_version=0.107.1`、`affects_gameplay=true`、无依赖。
- 行为替换两处：`Iteration.CanonicalVars` 基础值 2 → 1；`IterationPower.AfterCardDrawn` 去掉「每回合第一次」限制。
- 整卡呈现替换：卡名、卡面文本、卡图（两档）、Buff 名、Buff 描述、Buff 智能描述、Buff 图标（64/256 两档）。
- 15 个语言目录（deu/eng/esp/fra/ita/jpn/kor/pol/ptb/rus/spa/tha/tur/zhs/zht），30 个 JSON，键为
  `RE_EVOLVE.title/.description` 与 `RE_EVOLVE_POWER.title/.description/.smartDescription`。
- 2026-08-11 修订：删除 `IterationShapeGuard.cs`，`ModConfig.IsReplaceIterationEnabled` 恒 `true`，
  `ModEntry` 简化为直接 `PatchAll`；封面由 420×420 纯色占位换为 `pics/Evolve_small.png`（pck 体积 364 KB → 630 KB）。

### 简略技术细节

- 14 个 Harmony 补丁，分 6 个文件：`IterationCorePatches`（CanonicalVars）、`IterationPowerPatch`（AfterCardDrawn，
  Prefix 整体替换 + 反射调用 `PowerModel.Flash`）、`IterationTextPatches`（2 个 Postfix 换 `LocString`）、
  `EvolvePowerTextPatches`（3 个 Postfix）、`IterationPortraitPatches`（3 个 Prefix）、
  `EvolvePowerIconPatches`（4 个 Prefix）。
- 数值改法：只改 `CanonicalVars` 的基值，升级仍走原版 `UpgradeValueBy(1m)`，得到 1/2，无需补 `OnUpgrade`。
- 资源兜底：pck 内 `res://EvolveReplacementMod/images/...` 优先，失败回退 DLL 内嵌 PNG
  （`Image.LoadPngFromBuffer` → `ImageTexture`），纹理静态缓存。
- 素材：塔1 `images/1024Portraits/red/power/evolve.png`（500×380）2× 放大为 1000×760 与 250×190；
  `powers/powers.png` 图集 `128/evolve` 条目 → 64×64，另生成 256×256 大图标。
- 构建：`dotnet build -c Debug`（MSIL）→ Godot 4.5.1 headless `--import` → `--export-pack "Windows Desktop"`
  → 拷贝 `dll/pdb/json` 到 `mods/EvolveReplacementMod/`。构建结果 0 警告 0 错误，pck 35 个条目。

### 失败经验或实验教训

- 形状守卫与 API 存在性检测虽能「不满足即自动关闭」，但用户判定其收益不足、代码面变大，v0.1.0 修订时整体删除；
  代价是未来版本改动 `Iteration` 形状时 mod 会静默失效而不是主动降级，此边界已记入 ADR。
- 数值走 `CanonicalVars` 而非改 `OnUpgrade`：计划里预留了「`DynamicVars` 缓存未刷新」的备用方案
  （清理 `CardModel._dynamicVars`），但至今没有实机数据证明需要，故未实现。
- `assets/evolve_small.png` 被 `csproj` 内嵌进 DLL，实际代码路径只用 `evolve_big.png`，属冗余资源，未清理。
