# 进化（Evolve）替换 · 翻译审批文档

> 对应 mod：EvolveReplacementMod（塔2 Iteration「迭代」→ 塔1 Evolve「进化」，整卡替换）
> 原文来源：本地正版 STS1 `desktop-1.0.jar` 的 `localization/<lang>/cards.json`（键 `Evolve`）与 `localization/<lang>/powers.json`（键 `Evolve`）。
> 塔2 风格基准：v0.110.1 主包 `localization/<lang>/cards.json` 的 `ITERATION.title/.description` 与 `powers.json` 的 `ITERATION_POWER.title/.description/.smartDescription`。
> 本地化键（参考系列命名规则）：卡面 `RE_EVOLVE.title` / `RE_EVOLVE.description`；Buff `RE_EVOLVE_POWER.title` / `RE_EVOLVE_POWER.description` / `RE_EVOLVE_POWER.smartDescription`。
> 状态：**已批准（2026-08-10）**：用户确认主要语言无问题；其余语言按同一规则落地。文档为最终定稿，已用于 v0.1.0 构建。

## 转换规则（用户已拍板：整卡替换 + 塔1 数值 1/2 + 15 语言全量；沿用系列方案 B）

1. 卡面 `!M!` → `{IterationPower:diff()}`（基础 1，升级 2，随升级自动显示；变量名沿用塔2 原版 `IterationPower`，因为 CanonicalVars 仍是 `PowerVar<IterationPower>`）；
2. 需要单复数变化的语言在数字后追加 `{IterationPower:plural:...}`（eng/spa/ptb/fra/deu/ita/pol/tur）或 `{IterationPower:plural(ru):...}`（rus）；zhs/zht/jpn/kor/tha 直接放数字；
3. `NL` → 按塔2 各语言卡面风格合并为一行（塔2 ITERATION 卡面均为一行，Evolve 句子较短无需换行）；
4. 塔1 `#y`（状态/Status 关键词）与 `#b`（数值）：卡面不加金色（塔2 原版 ITERATION 卡面无 `[gold]`）；Buff 描述去掉 `#y`；Buff 智能描述用 `[blue]{Amount}[/blue]` + `{Amount:...}` 复数语法（参考塔2 `ITERATION_POWER.smartDescription` 各语言结构）；
5. 方案 B 排版：清多余空格；zht 补句号；ita 修正原文“Quando peschi uno Stato Peschi”双谓语笔误；kor 清“!M! 장”空格；jpn 清“状態異常 カード”空格；rus 用 `plural(ru)` 三形；tha 按语言习惯不加句号；
6. `esp` 与 `spa` 分开写：spa 沿用塔1 原文人称（robes/roba），esp 按塔2 esp 目录人称风格（robas/robas），共 15 个目录；
7. 塔2 tha 原版缺 `ITERATION_POWER.title`，本 mod 补上塔1 官方泰语名（系列先例：Recycle 同款处理）。
